# Source Map

This plugin is a learning workflow over public source repositories. It should cite and
link sources, not redistribute their full text.

## Sources

- Donne Martin, `donnemartin/system-design-primer`
  - URL: https://github.com/donnemartin/system-design-primer
  - Use for: broad topic map, study guide, interview prep framing, core tradeoffs.
  - License noted in repository README: Creative Commons Attribution 4.0 International.

- Karan Pratap Singh, `karanpratapsingh/system-design`
  - URL: https://github.com/karanpratapsingh/system-design
  - Use for: course-like progression, fundamentals, architecture patterns, common cases.
  - License file indicates Creative Commons Attribution-NonCommercial-NoDerivatives 4.0.
  - Do not adapt or redistribute substantial content. Use links and original commentary.

- Admol, `Admol/SystemDesign`
  - URL: https://github.com/Admol/SystemDesign
  - Use for: Chinese learning orientation and case list inspired by System Design Interview.
  - Repository README says the translation is for learning/research reference and not for
    public distribution or commercial use.
  - Do not package, quote, or reproduce chapter content. Use only case names and source links.

## Usage Rules

- Never paste large passages from upstream repositories.
- Prefer source links, short summaries, original rubrics, and practice prompts.
- Attribute ideas when pointing the user to a specific source.
- If asked for exact upstream text, provide a link and a brief summary instead.
- Keep this plugin useful even without network access by storing only topic names, case names,
  workflows, and evaluation criteria.
